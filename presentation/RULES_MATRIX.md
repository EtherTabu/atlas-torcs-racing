# Presentation boundaries

Governing evidence: supplied IBM Customising Guide sections 3.1–3.3 and the
IBM submission screenshot. Customising instructions describe texture editing;
they do not explicitly authorize a branded official fastest-lap recording.
Therefore the official video uses original track textures. Branded track copies
are reserved for the separately labelled engineering showcase. RC1 stays frozen.

| Element | IBM explicitly permits customization? | Safe for official submission? | Action |
|---|---|---|---|
| Track banners | Yes, banner textures with team names/logos/slogans | Official-video scope not explicit | Prepare isolated showcase textures; official run stock |
| Advertising boards | Yes, section 3 describes boards beside the track | Same ambiguity | Only identified visual board textures in showcase |
| Trackside signs | General signs mentioned; not every sign classified as banner | Not established for racing markers | Preserve braking/direction signs |
| Car livery | General editing guide yes; official submission says do not change | Only unchanged qualified file | Preserve exact RC1 bytes |
| Car model | Submission forbids dynamics changes | Unchanged only | No changes |
| Track geometry | No affirmative permission supplied | Unchanged only | No changes |
| Race configuration | Setup workflow provided; no performance customization permission | Exact qualified configuration | No changes |
| HUD/display | No affirmative customization permission supplied | Existing normal GUI | Overlays only in explainer |
| Camera/view | No affirmative customization permission supplied | Existing qualified view | No official camera modification |
| README/GitHub presentation | Public repository required; visual design unspecified | Does not change racing evidence | Factual project presentation |
| Video title/description | Video required; editorial design unspecified | Factual identification only | Exact result; no endorsement/ranking claims |
| Engineering explainer visuals | Not an official-run modification | Separate from official footage | Label provenance and actual measurements |

No IBM endorsement, employment, victory, ranking or world-record claim is made.
